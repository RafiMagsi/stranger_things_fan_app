# Clips

Everything here is generated by `tool/build_fan_media.py` from the fan
edits in `docs/videos` - don't edit by hand; change the script and re-run.
Credits for every file: `lib/data/fan_media.dart`.

    reel_<slug>.mp4      The Reel: whole edits with sound, upright
                         (sideways landscape footage turned 90°)
    char_<id>.mp4        silent dossier loop for every character
    monster_<id>.mp4     Bestiary loops
    hero_finale.mp4      the Home banner
    gate_*.mp4           what the Gate shows of the other side
    ud_*.mp4, bikes_night.mp4, clock_loop.mp4   other screen loops

Stills from the same footage are in `assets/images` (char_*, monster_*,
loc_*, season_*, reel/, fan/), and the soundtrack and soundboard captures in
`assets/audio/captures`.

This is a personal build's media: it's other fans' work around Netflix's
footage. Remove it with `python3 tool/build_fan_media.py --clean` before
publishing the app anywhere.
